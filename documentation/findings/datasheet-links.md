# Datasheet and Reference Links

Links collected while checking the PowerLenz parts. Last reviewed 23 Nov 2026. Manufacturers revise datasheets, so confirm the revision before relying on a number.

Local copies of the documents we have downloaded are kept in [../datasheets/](../datasheets/README.md), organised by function.

**Status key**
- **Read:** the full text was extracted and read.
- **Listing only:** only a distributor or search listing was read, not the manufacturer document.
- **Not read:** the link exists but its contents were not checked.

## TI application notes named in the ADS131M04 page

Identifiers only. Search ti.com for them. None has been read.

- SBAA506: ADC overstress protection circuit (relevant to input protection). [ti.com/lit/an/sbaa506/sbaa506.pdf](https://www.ti.com/lit/an/sbaa506/sbaa506.pdf) downloads, but the text could not be extracted here.
- SBAA385: two-phase Rogowski coil AFE.
- SBAA106: communication methods for data integrity.
- SBAA230: digital filter types.

## Re-reading a saved PDF

PDF text can be extracted with `pdftotext -layout file.pdf out.txt` (from poppler). Some distributor links return an HTML landing page instead of the PDF.

See also: `datasheet-verification-checklist.md` in this folder, which records what each datasheet says and what it changes in the design.
